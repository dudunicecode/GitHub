seção 01 · aproximação

O que é o GitHub?

Uma plataforma de hospedagem de código e colaboração construída sobre o Git — o sistema de controle de versão distribuído mais usado do planeta. Na prática, funciona como uma rede social para quem programa.

"Se o código é o produto, o GitHub é a fábrica, a vitrine e o ponto de encontro."

Hospedagem de repositórios

Cada projeto vive em uma pasta versionada com todo o histórico de alterações do código.

Colaboração em tempo real

Times inteiros — ou comunidades de milhares de pessoas — contribuem para o mesmo projeto sem sobrescrever o trabalho umas das outras.

Rede social para devs

Perfis, seguidores, estrelas e contribuições públicas formam um currículo vivo de quem programa.

seção 03 · comparativo

Git × GitHub

Duas coisas diferentes que trabalham juntas — e a confusão entre os dois nomes é a primeira coisa a esclarecer.

git
  • Software de controle de versão, criado por Linus Torvalds em 2005
  • Roda localmente, no computador de cada desenvolvedor
  • Cuida do histórico de versões do código
  • Não depende de nenhuma empresa específica
github
  • Plataforma (site + serviço) que hospeda repositórios Git na nuvem
  • Roda na web, acessível de qualquer lugar com internet
  • Adiciona colaboração, interface visual, automações e comunidade
  • É um produto da Microsoft — assim como GitLab e Bitbucket são concorrentes
seção 04 · sobrevoo do fluxo

Como o GitHub funciona

O caminho que uma ideia percorre até virar parte do projeto principal.

Repositório

Onde os arquivos e o histórico do projeto vivem.

→

Commit

Um "salvamento" com uma mensagem do que mudou.

→

Branch

Cópia paralela para desenvolver sem afetar o principal.

→

Pull Request

Pedido formal para juntar as mudanças, revisado por outras pessoas.

→

Merge

A junção efetiva das mudanças aprovadas ao código principal.

seção 05 · a cidade digital

Principais recursos

O ecossistema construído em torno de cada repositório.

Projects

Quadros estilo Kanban para planejar e acompanhar o trabalho.

Discussions

Fórum para debater ideias e construir comunidade em torno do projeto.

Pages

Hospedagem gratuita de sites estáticos direto do repositório.

Codespaces

Ambiente de desenvolvimento completo na nuvem, no navegador.

Actions

Automação de testes e implantações — o motor do CI/CD.

Wiki

Documentação colaborativa vinculada a cada repositório.

Marketplace

Loja de apps, ações e integrações para estender a plataforma.

Sponsors

Apoio financeiro para mantenedores de projetos open source.

seção 06 · perímetro de defesa

Segurança no GitHub

Proteção do código do primeiro ao último commit.

Dependabot

Identifica dependências desatualizadas ou vulneráveis e sugere — ou aplica — atualizações automaticamente.

Code scanning

Analisa o código em busca de vulnerabilidades antes que cheguem à produção.

Secret scanning

Detecta senhas, tokens e chaves de API expostas acidentalmente no código.

Autenticação em dois fatores

Camada extra de segurança para contas, hoje incentivada — e em muitos casos exigida.
